## 成绩/绩点: 多多益善

> 绩点高 = 会做题

![](assets/README/file-20260920230822826.jpg ':size=30%')

保研首先看的就是绩点, 绩点是基础的体现(实则不完全对应), 不管是转入转出都需要.

中南的绩点是百分制的加权成绩, 有些学校可能会进一步换算成5分/4分制的GPA, 具体还要以学校的要求为准. 本人经过三年的努力, 也是比较荣幸能拿到专业第二(2/78)的成绩排名, 过程不算容易, 自我感觉还是凭借对集成电路这个专业的一股热爱和不错的前景而坚持下来的.

然而很尴尬的是, 绩点这东西, 只有在你没拥有的时候才感觉有用, 因为它代表不了什么, 只能代表你有一定的应试能力和最终获取一个转出的入场券. 这点很难给出经验, 因为我了解到很多人很努力, 学的也算扎实, 但是考试总发挥不好, 也看到很多人仅仅考前突击几天就能发挥很好, 稳拿名额. 这一点因人而异.

如何搞好绩点呢? 我认为不是对各门课程学的多扎实多通透, 这点是转入资格[专业课程](?id=面试笔试-是骡子是马拉出来遛遛/###专业课程)等其他地方所要求的, 而绩点是在**任课老师的评价体系**下, 尽最大可能获取高分, 本质还是**做题**. 下面以中南大学2023级微电子专业课程体系为例, 给出我搞绩点的拙见.<div>
